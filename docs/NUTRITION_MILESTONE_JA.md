# 食事記録・日別集計の開発記録

確認日：2026-11-06

## 今回の変更

ローカルにあった食事画面とCSSを使い、手入力の登録と日別集計を公開する。
新しく最初から作ったという扱いではなく、既存実装の認証・入力検証・集計を見直した段階。
ログイン本人のIDで保存・取得し、POSTにはCSRFトークンを必要とする。
食品名は200文字以内、日付は今日以前、栄養値は0～999999.99の小数2桁まで。
範囲はDBに保存できる値に合わせたもので、栄養面の推奨値ではない。

## 分析の説明

- 食べた量に相当するカロリーとタンパク質を登録する。
- 同じ日の450.25kcalと100kcalは、日計550.25kcalになる。
- タンパク質20.50gと未入力の食品がある日は、合計20.50gとは断定できない。
  今日の合計は「—」、履歴の日計は「Incomplete」、個別の未入力は「Unknown」と表示する。
- 0gと入力した記録は既知の0として集計する。全件未記録も0とは表示しない。
- 件数は食品の登録件数。同じ食事で2品登録した場合、2件であり食事回数ではない。
- 今日の判定にはPHPサーバーの日付を使う。

未入力を0に置き換えないことが、集計を誤解させないためのポイント。
