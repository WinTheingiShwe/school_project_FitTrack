# FitTrack

Fitness Data Management and Analysis Web Application

## Overview

FitTrack is a web application for recording and analyzing personal fitness data.

## Main Features

- Record daily weight
- Record gym training
- Record nutrition data
- View fitness history
- Analyze fitness data
- Display data with charts

## Technologies

- HTML
- CSS
- JavaScript
- PHP / Laravel
- PostgreSQL
- Excel
- Power BI
